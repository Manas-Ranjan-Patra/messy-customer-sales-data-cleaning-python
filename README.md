# messy-customer-sales-data-cleaning-python

## 📝 Overview
This project performs an in-depth analysis of sales data to uncover key business insights such as top-performing products, customer behavior, and revenue trends.  
The project uses **Python**, **Pandas**, **NumPy**, and **Matplotlib** for data manipulation, cleaning, and visualization.

## 💡 Objective
The main goal of this project is to:
- Analyze the sales dataset to identify patterns and trends.
- Handle missing, inconsistent, and categorical data effectively.
- Perform descriptive statistical analysis.
- Visualize important metrics to support business decisions.

## 🗂️ Dataset Information
- **File Name:** `sales_data_sample.csv`
- **Source:** Provided for data analytics practice.
- **Description:**  
  The dataset contains transactional sales data including information such as:
  - `OrderDate` — Date of the transaction  
  - `CustomerName` — Name of the customer  
  - `ProductLine` — Category of the product  
  - `QuantityOrdered` — Units ordered  
  - `PriceEach` — Price per unit  
  - `Sales` — Total sales amount  
  - `Country`, `City`, `State` — Location details  
  - `Status` — Order completion status  


## 🧠 Key Features / Learnings

- Data cleaning (handling missing values and inconsistent formats)
- Feature extraction and transformation
- Statistical analysis (mean, median, mode, standard deviation)
- Data visualization using bar, line, and pie charts
- Understanding sales performance across regions and products
- Use of **regular expressions (regex)** for data extraction
- Handling **warnings** and **pandas inplace operations**

---

## 📊 Analysis / Results

Some of the insights obtained include:

- The top-selling product categories and regions  
- Seasonal trends in sales performance  
- Customer purchase behavior based on location and order status  
- Impact of discounts and pricing on sales performance

## 🧾 Conclusion

The project successfully demonstrates how data analytics can be applied to real-world sales data.  
It emphasizes the importance of **data preprocessing** and **visualization** in extracting actionable business insights.
